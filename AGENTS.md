# UFC Market Lab operating rules

- Read PROGRESS.md and ROADMAP.md before work; inspect only relevant files and recent diffs. Repository root is this directory, not its older exported sibling.
- Standing approval covers normal development/research/local tests. PAPER only. Real orders, purchases/subscriptions/credits and credential exposure require separate explicit human approval. Do not consume account reset credits.
- Main session: prefer Sol Medium/High; use economical Luna for narrow routine subtasks when supported. At most two concurrent subagents by default; extra agents require a demonstrable saving. Never delegate merely to summarize. Reserve Ultra for unusually difficult ML/architecture/concurrency/debugging.
- A continuation batch is at most three meaningful tasks, normally under 20 minutes. Check available usage once; if exhausted, save state and stop. Do not poll limits or create duplicate schedules.
- Before edits, acquire `python scripts/development_lease.py acquire --owner YOUR_RUN_ID`. If busy, do not edit. Retain the returned coordination token locally; release in a finally step with `... release --token TOKEN`. Lease expires after two hours for crash recovery: finish well before expiry. Delegated tasks share the owning run's lease and edit disjoint files.
- Do not rerun verified research, repeat web searches, redownload pinned cached files or retrain unchanged models. Source data lives under ignored data/research/nlbair; fitted research-only artifacts are versioned under artifacts/research. Pin/hash/attribute any changed source.
- No fabricated market prices, event times, datasets, metrics or positional rates. Historical snapshot models lack observed availability; never load them into the approved execution-model path. Explicitly opted-in historical PAPER experiments use AutoPaper only, keep live eligibility false, and require reviewed identity/rules/schedule plus existing risk gates. Twelve seconds remains a hypothesis until paired real data supports it.
- Run targeted tests after small changes. Run `python scripts/check.py` at an integration milestone; `python scripts/scan_secrets.py` before publication. Do not repeat full suites without a new change/failure/concern. Use the existing installed interpreter; this checkout can reuse `../ufc-research/.venv/Scripts/python` locally.
- Keep collection/paper execution deterministic ordinary services, independent of Codex/LLM calls. One database writer via writer_lease; WAL-safe verified atomic backups; no credentials in logs or Git. Raw events remain append-only.
- Save reviewable Git changes without overwriting others. Update concise progress only on meaningful changes, including actual checks, limitations and next task. Do not create another conversation or duplicate automation.

- Primary UX is historical Practice: one Start button, visible automatic decisions/orders, separated synthetic prices, fixed pre-fight probability and hidden future results. Preserve practice-account isolation; never present scenario P&L as historical exchange returns. Product gaps and acceptance criteria are in docs/PRODUCT_ISSUES.md.
